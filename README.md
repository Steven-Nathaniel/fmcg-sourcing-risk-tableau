# FMCG Sourcing Risk Analysis: Dampak Perubahan Iklim terhadap Rantai Pasok Pangan Indonesia

Proyek kelompok (3 orang) mata kuliah Data Visualization (2026), Universitas Multimedia Nusantara.

**Tools:** Tableau · **Pendekatan:** CRISP-DM, exploratory visual analytics

## Data
Dataset longitudinal **850 observasi**, **34 provinsi**, dan **41 variabel** (2000–2024): iklim, bencana, produksi pangan, dan harga.

## Yang Dikerjakan
- Dashboard dan story Tableau untuk tren iklim, korelasi faktor iklim dengan hasil panen, dan peta risiko provinsi.
- Dua indeks komposit: **Integrated Supply-chain Sustainability Balance (ISSB)** dan **Integrated Risk & Growth Sourcing Compass (IRGSC)**.
- Model **forecasting eksponensial** untuk proyeksi harga pangan.

## Temuan Utama
- Suhu rata-rata naik 0,89°C, curah hujan turun 21,7%, dan frekuensi bencana ekstrem naik hingga 2,5 kali.
- Tingkat gagal panen nasional naik dari **6,01% menjadi 14,56%**.
- **Jawa Barat** dan **Sumatera Utara** menjadi sentra sourcing paling resilien (skor ISSB tertinggi).
- Forecasting mendeteksi titik kritis lonjakan harga pangan lokal pada **2028**.
